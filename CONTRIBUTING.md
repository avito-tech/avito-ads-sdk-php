# Участие в разработке

Спасибо за интерес к проекту! Ниже — короткая памятка для контрибьюторов.

## Окружение

- PHP >= 7.4 (код должен оставаться совместимым с 7.4 и 8.x).
- Composer.

```bash
composer install
```

## Перед отправкой Pull Request

Убедитесь, что проходят проверки:

```bash
composer test       # PHPUnit
composer phpstan    # статический анализ (PHPStan, level 6)
composer cs         # стиль кода (PSR-12)
```

При необходимости автоматически исправить стиль:

```bash
composer cs-fix
```

## Соглашения по коду

- Идентификаторы (классы, методы, переменные) — на английском языке.
- PHPDoc и пользовательская документация — на русском языке.
- Избегайте синтаксиса, доступного только в PHP 8 (промоушен свойств в
  конструкторе, `enum`, `readonly`, `match`, union-типы в сигнатурах, `?->`),
  чтобы сохранить совместимость с PHP 7.4. Union-типы допустимы только в PHPDoc.
- Новый код покрывайте тестами.

## Сообщения об ошибках

Опишите шаги воспроизведения, версию PHP и ожидаемое поведение. Не прикладывайте
реальные `client_secret` и токены.
